YAML or JSON. Define endpoints, params, bodies, headers, auth, environments — all in one place.

Strict Validation

Modular Splits

Auth Schemes

Bearer, API Key, Basic, OAuth2 — collection-level defaults with per-endpoint overrides.

Schema Example

Reads Like Documentation

Clear, minimal YAML. No ceremony.

api-schema.yml 
apinox: "1.0"
name: my-api
version: 1.0.0
base_url: https://api.example.com

auth:
  default: jwt
  schemes:
    - id: jwt
      type: http
      scheme: bearer
      header: Authorization
      prefix: "Bearer "

groups:
  - id: users
    name: Users
    description: User management

endpoints:
  - id: list-users
    name: List Users
    group: users
    method: GET
    path: /users
    query_params:
      - name: page
        type: integer
        required: true
    responses:
      - status: 200
        description: User list
        examples:
          - name: default
            value: {"users": [...], "total": 42}
